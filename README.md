# 皮克敏蘑菇時間紀錄器（Pikmin Bloom Mushroom Tracker）

專為手機使用者（iOS 與 Android）量身打造之**純黑 OLED 省電型**皮克敏蘑菇出現與重生時間追蹤工具。具備漸進式網頁應用（PWA）架構，支援離線快取、前台螢幕常亮、和弦提示音效、本機推播通知與一鍵匯入系統行事曆，可直接透過 GitHub Pages 免費架設與使用。

---

## 核心功能特色

1. **OLED 極致省電介面**：
   * 全域採用 `#000000` 純黑色票，使 OLED 面板像素完全斷電熄滅，大幅降低手機耗電量。
   * 內建「微光常亮 HUD 模式」，利用 Screen Wake Lock API 阻止手機螢幕休眠，放於辦公桌或床頭即為專屬倒數時鐘。
   * 內建每 45 秒定時像素微位移（Pixel Shift）防烙印防護，長時常亮亦不傷螢幕。
2. **多地點點位與雙模式倒數**：
   * **剛打完模式（一鍵 15 分鐘倒數）**：擊破蘑菇後一鍵啟動常規 15 分鐘重生倒數。
   * **正在打模式（自訂時間倒數）**：支援預設 15 分、30 分、1 小時、2 小時或任意自訂戰鬥時間，戰鬥中亦可隨時切換為「提早打完」無縫銜接 15 分鐘冷卻。
3. **多重提醒機制（抗休眠防漏失）**：
   * 前台：Web Audio API 合成溫和水晶和弦琶音，配合手機震動反饋。
   * 系統通知：支援 Web Notification API 瀏覽器本地推播。
   * 離線行事曆備案：一鍵匯出標準 `.ics` 行事曆檔案，無縫整合 iOS 行事曆與 Google Calendar 內建鬧鐘。
4. **每日免費額度管理**：
   * 提供 3 次免費挑戰額度計數器，支援每日午夜（00:00 當地時間）自動判定與重置。
5. **完整 PWA 支援與離線快取**：
   * 整合 Workbox 離線快取技術，無網路環境亦可完整離線運作。
   * 支援 iOS（Safari）與 Android（Chrome）「加入主畫面」，享有如同原生 App 之全螢幕沉浸體驗。

## 皮克敏蘑菇機制全解析

### 一、 蘑菇出現與重生頻率（15 分鐘黃金週期）
* **重生冷卻時間**：當某一地點的蘑菇被擊破後，該據點會進入冷卻隱藏狀態。根據遊戲實測機制，通常在**擊破後的 15 分鐘內**（多數於 10 至 15 分鐘區間）重生為一朵新蘑菇。
* **隨機性**：重生之新蘑菇顏色、尺寸（普通／大型／巨大）與特殊屬性均為獨立隨機生成。若在特殊活動期間，特定點位亦有機率直接出現活動神秘蘑菇。
* **戰略價值**：掌握 15 分鐘的重生節點，能讓您在第一時間組隊挑戰最新出爐的高星級蘑菇，避免被路過玩家佔滿名額。

### 二、 每日免費挑戰額度與重置規則
* **挑戰次數**：每位玩家每日擁有 **3 次免費挑戰額度**。
* **重置時間**：於**每日午夜 00:00（玩家手機所在當地時區）**全面重置為 3 次。
* **蘑菇儲值券**：使用儲值券挑戰不會扣除每日 3 次免費額度。建議玩家將每日免費額度優先保留給巨大蘑菇或活動特殊蘑菇。

### 三、 蘑菇顏色與屬性剋制
* **常規顏色**：紅色、黃色、藍色、紫色、白色、羽翼、岩石。派入同色皮克敏或具備相應飾物（裝飾皮克敏）可獲得高額攻擊力加成。
* **特殊屬性**：烈火蘑菇（需紅隊）、水流蘑菇（需藍隊）、電力蘑菇（需黃隊）、劇毒蘑菇（需白隊）。派入非對應屬性之皮克敏無法出戰或效率低落。
* **巨大與神秘蘑菇**：血量龐大但掉落之精華果實與明信片品質最佳，建議號召好友共同合擊。

## 實戰操作範例教學

### 範例情境 A：剛剛擊破住家附近的蘑菇（掌握重生時間）
1. 打開本應用，找到「住家後方公園」卡片。
2. 點擊卡片上的 **「剛打完 (15分)」**。
3. 頁面立刻展開 15 分鐘動態倒數條，並計算出精確重生鐘點（例如預計 `14:25:30` 重生）。
4. （可選）點擊卡片右上方的 **「行事曆提醒」**，手機系統會自動彈出日曆並設定鬧鐘。
5. 倒數歸零時，手機將響起和弦鈴聲並震動，卡片轉為綠色「已重生出現！可立即進攻」，提醒您開遊戲搶先派兵。

### 範例情境 B：派隊進攻需耗時 1 小時的巨大蘑菇
1. 派兵出發後，找到「捷運站南門廣場」點位。
2. 點擊 **「正在打 (自訂)」**，選擇 `60 分鐘`（或手動輸入分鐘數）並點擊啟動。
3. 系統即時顯示戰鬥剩餘倒數。若戰鬥過程中好友加入合擊讓時間縮短，可直接點擊 **「提早打完」**，立即轉換為 15 分鐘重生倒數。

### 範例情境 C：桌面長時常亮監控（OLED HUD 模式）
1. 將手機平放於辦公桌或床頭支架上。
2. 點擊頂部導航列的 **「HUD」** 按鈕。
3. 畫面切換為純黑 `#000000` 背景，僅以低耗能微光文字展示最近一朵即將重生的蘑菇大字倒數。
4. 系統自動維持螢幕不熄滅（Wake Lock），並每 45 秒微調位置防止螢幕烙印，時間到達時全螢幕微光閃爍並播放鈴聲。

## 手機端安裝教學（加入主畫面 PWA）

### iOS (iPhone / iPad) 使用 Safari：
1. 使用 Safari 瀏覽器打開本網頁。
2. 點擊底部導航列中央的 **「分享」** 圖示（方框帶向上箭頭）。
3. 向下滾動選單，點選 **「加入主畫面」**（Add to Home Screen）。
4. 點擊右上角「新增」。完成後手機主螢幕將出現專屬蘑菇圖示，啟動時即為無網址列的全螢幕獨立應用。

### Android 使用 Chrome：
1. 使用 Chrome 瀏覽器打開本網頁。
2. 點擊右上角 **「選單」** 圖示（三個直點）。
3. 選擇 **「安裝應用程式」** 或 **「新增至主螢幕」**。
4. 點擊確認即可完成安裝。

## 如何自行部署至 GitHub Pages (github.io)

本專案已完整內建 GitHub Actions 自動部署工作流程，只需依照以下步驟操作：

1. **建立 GitHub 儲存庫**：
   * 在 GitHub 上建立一個新的公開或私人儲存庫（Repository），例如 `pikmin-tracker`。
2. **推送原始碼**：
   ```bash
   git init
   git add .
   git commit -m "feat: initial commit of pikmin tracker"
   git branch -M main
   git remote add origin https://github.com/<你的帳號>/<你的儲存庫名稱>.git
   git push -u origin main
   ```
3. **啟用 GitHub Pages**：
   * 進入儲存庫的 **Settings** -> **Pages**。
   * 在 **Build and deployment** 下方的 **Source** 選擇 **「GitHub Actions」**。
4. **自動發布**：
   * 每次推送至 `main` 分支時，GitHub Actions 會自動執行編譯打包並發布至 `https://<你的帳號>.github.io/<你的儲存庫名稱>/`。
