# 皮克敏蘑菇時間紀錄器（Pikmin Bloom Mushroom Tracker）

專為手機使用者（iOS 與 Android）量身打造之**純黑 OLED 省電型**皮克敏蘑菇出現與重生時間追蹤工具。具備漸進式網頁應用（PWA）架構，支援 5 分鐘極速重生倒數、1~3 分鐘提前警示、皮克敏三大蘑菇體系分類與派遣限制、離線快取、前台螢幕常亮、和弦提示音效、本機推播通知與一鍵匯入系統行事曆，可直接透過 GitHub Pages 免費架設與使用。

---

## 核心功能特色

1. **5 分鐘重生黃金週期**：
   * 根據最新遊戲實測機制，蘑菇被擊破後於 **5 分鐘**內迅速重生。
   * 提供「剛打完 (5分)」一鍵啟動倒數，並計算出精準重生時點。
2. **提前 1~3 分鐘智能預警**：
   * 接近重生時間（剩餘 1~3 分鐘，預設 2 分鐘）時，系統自動發出預警通知、震動與卡片琥珀色微光閃爍，提醒玩家預先開啟遊戲排隊就位。
   * 到期準時發出完成和弦音與正式通知。
3. **皮克敏三大蘑菇體系與派遣限制管理**：
   * **顏色菇（基礎色菇）**：紅、黃、藍、紫、白、粉紅（羽翼）、灰色（岩石）、冰藍色。
   * **元素菇（屬性菇）**：嚴格限定派遣特定屬性皮克敏（火蘑菇限定紅、水蘑菇限定藍、電蘑菇限定黃、毒蘑菇限定白、水晶蘑菇限定岩石）。
   * **活動菇與巨型活動菇**：當月主題活動菇（全天候提供活動精華與道具）與**巨型活動菇（週末六、日限定登場，獎勵最豐厚）**。
4. **每日免費 3 次額度跨日自動重置**：
   * 跨越午夜 00:00（當地時間）自動偵測並重置免費額度為 3 次，無論前台操作或背景重新開啟皆能精準刷新。
5. **OLED 極致省電與微光常亮 HUD**：
   * 全域採用 `#000000` 純黑色票，使 OLED 面板像素完全斷電熄滅，大幅降低手機耗電量。
   * 內建「微光常亮 HUD 模式」，利用 Screen Wake Lock API 阻止手機螢幕休眠，放於辦公桌即為專屬倒數時鐘。
   * 內建每 45 秒定時像素微位移（Pixel Shift）防烙印防護，長時常亮不傷面板。
6. **明亮模式（Light Mode）切換**：
   * 頂部導航列提供一鍵切換太陽／月亮圖示，兼顧白天戶外強光閱讀體驗。
7. **一鍵隨機名稱生成**：
   * 新增點位時提供骰子隨機名稱功能，內建多處台灣知名地標、公園水池與生活街角，省去手動打字時間。

## 皮克敏三大蘑菇體系規則詳解

### 一、 顏色菇（基礎色菇）
* **種類**：紅、黃、藍、紫、白、粉紅、灰色（岩石）、冰藍色。
* **派遣規則**：所有皮克敏皆可出戰。派出相同顏色或對應裝飾之皮克敏享有攻擊力數值加成。

### 二、 元素菇（屬性菇）
* **火蘑菇**：僅限派出 **紅皮克敏** 出戰。
* **水蘑菇**：僅限派出 **藍皮克敏** 出戰。
* **電蘑菇**：僅限派出 **黃皮克敏** 出戰。
* **毒蘑菇**：僅限派出 **白皮克敏** 出戰。
* **水晶蘑菇**：僅限派出 **岩石皮克敏** 出戰。
* 其餘顏色皮克敏無法進入該蘑菇戰鬥，建議平時多培養各單一屬性主力部隊。

### 三、 活動菇與巨型活動菇
* **當月活動菇**：配合當月主題活動持續出現，擊破可獲得活動專屬特別精華與限定道具。
* **巨型活動菇**：**每週六、日週末限定登場**。具備超高血量與更高參戰人數上限，通關後掉落全遊戲最豐厚的果實、精華與獎勵。本應用程式在週末會自動亮起週末限定標籤。

## 實戰操作範例

### 情境 A：打完公園剛重生的火蘑菇（5 分鐘倒數 + 提前預警）
1. 點擊「新增」，選擇「元素菇」-「火蘑菇」，可點擊「隨機生成名稱」帶入公園名稱。
2. 擊破後在卡片上點擊 **「剛打完 (5分)」**。
3. 倒數至剩餘 2 分鐘時，系統發出提前通知，提醒您提早打開遊戲並備妥紅皮克敏。
4. 倒數歸零時，播放和弦鈴聲且卡片轉為綠色「已重生出現」，立即派兵奪得先機。

### 情境 B：週末攻略巨型活動菇（行事曆提醒）
1. 週末遇到巨型活動菇，點擊「正在打 (自訂)」輸入預計戰鬥時間（如 120 分鐘）。
2. 點擊 **「行事曆提醒」**，系統將產生包含提前 2 分鐘與準時鬧鐘的 `.ics` 檔案，自動加入手機行事曆。
3. 戰鬥結束或隊友提早擊破時，點擊「提早打完」，即可立即無縫轉換為 5 分鐘重生倒數。

## 手機端安裝教學（加入主畫面 PWA）

### iOS (Safari)：
1. 使用 Safari 打開網頁。
2. 點擊底部中央的 **「分享」** 圖示。
3. 向下滾動點選 **「加入主畫面」**。

### Android (Chrome)：
1. 使用 Chrome 打開網頁。
2. 點擊右上角選單（三個直點）。
3. 選擇 **「安裝應用程式」** 或 **「新增至主畫面」**。
